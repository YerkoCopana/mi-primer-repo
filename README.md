# Agenda de contactos

Proyecto de práctica de Git.

## Cómo usar

Esta agenda de práctica tiene los siguientes archivos:

- `contactos.txt`: nombres, teléfonos y correos de contactos ficticios.
- `tareas.txt`: tareas pendientes para la práctica de Git.
- `compras.txt`: lista de compras de ejemplo.
- `.gitignore`: evita registrar archivos temporales, de editores y `secretos.txt`.

Abre los archivos con cualquier editor de texto. Usa `git log --oneline --graph --all`
para observar los commits y las fusiones de ramas.
